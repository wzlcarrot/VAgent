# ViewHub AI 智能助手 — 用户使用说明

## 一、系统简介

ViewHub AI 是一个视频平台的智能助手，支持**多轮对话**和**流式输出**（打字机效果）。你可以通过自然语言与 AI 对话，完成视频问答、视频推荐、个人数据查询等任务。

---

## 二、功能清单

| 功能 | 示例提问 | 说明 |
|------|---------|------|
| **智能问答** | "这个视频讲了什么"、"视频的重点是什么" | 基于当前视频内容回答 |
| **视频推荐** | "给我推荐一个视频"、"有什么好看的" | 根据你的观看历史推荐 |
| **用户数据查询** | "我今天点了多少赞"、"我的收藏有哪些" | 查询点赞、收藏、播放记录 |
| **平台客服** | "怎么上传视频"、"如何修改个人信息" | 回答平台使用问题 |
| **多轮对话** | 追问 "那第二个呢"、"再详细说说" | AI 记得前几轮对话内容 |
| **流式输出** | 所有回答逐字显示 | 打字机效果，不需要等待完整响应 |
| **历史恢复** | 刷新页面后对话仍在 | 所有对话自动保存到服务器 |

---

## 三、完整交互链路

### 3.1 首次使用

```
① 打开页面 → 自动创建新对话
② 在输入框提问（如 "给我推荐一个视频"）
③ AI 逐字流式回答（打字机效果）
④ 回答完成后，左侧 sidebar 自动出现历史会话
```

### 3.2 多轮对话

```
① 第1轮："这个视频讲了什么"
     → AI 根据视频信息回答

② 第2轮（追问）："那第二个呢"
     → AI 记得第1轮内容，理解"第二个"指什么
     → 继续回答

③ 第3轮（继续追问）："再详细讲讲"
     → AI 继续承接上下文回答
```

### 3.3 刷新页面后恢复

```
① 刷新浏览器
② 左侧 sidebar 自动加载历史会话列表
③ 点击某个历史会话 → 加载完整对话记录
④ 可继续提问
```

### 3.4 切换任务类型

```
提问"这个视频讲了什么"    → 自动进入视频问答模式
提问"推荐一个视频"        → 自动进入推荐模式
提问"今天点了多少赞"      → 自动进入数据查询模式
提问"怎么上传视频"        → 自动进入客服模式
```

无需手动切换，AI 自动判断问题类型。

## 四、常见问题

**Q: AI 回答不准确怎么办？**
A: 可以再次追问或换一种问法。视频问答需要提供 `video_id`，推荐需要你有观看历史。

**Q: 多轮对话最多能记住多少？**
A: 最近 5 轮对话（10 条消息）。超出范围的早期对话会被截断。

**Q: 对话记录会丢失吗？**
A: 不会。所有对话保存到服务器数据库，刷新页面或重新打开都能恢复。

**Q: 登录信息是什么？**
A: 默认关测试账号。本地演示要开的话，自己在 `.env` 里设邮箱和口令哈希，不要用弱口令。
