# 面试速记（一页，背这个就够）

> 原则：**别背细节，背框架。** 细节现场从框架推导；数字记 6 个；故事记 3 个。

## 一、万能框架（3 个，能推出一大片）

**① `Agent = Model + Harness`**
Harness = 模型之外的全部工程：执行引擎 / 工具 / 上下文 / 控制 / 观测 / 评测。

**② 记忆三层**
```
工作记忆 = Workflow State（请求完即释放）
短期记忆 = Redis + 压缩（5 轮 / 3000 token）
长期记忆 = PostgreSQL user_memory（提取器 + LLM Judge）
```

**③ Agent Loop 双循环**
```
外循环(turn)  = 一次请求：路由 → 并行派发 → 仲裁
内循环(step)  = 一次模型决策：decide → execute → observe（≤ max_steps）
```

## 二、万能原则（1 句）

> **用代码管边界、用模型管语义。**

（权限/流程/兜底=代码；理解/判断/生成=模型）

## 四、必背故事（3 个，各 1 句）

1. **语义重试**：第一版净增益 0% → 改提示词 → 救回 80%+
2. **记忆冲突**：相似度同义改写 1/50 → LLM Judge 49/50（99.3%）
3. **省步**：ablation 把 video QA 平均步数 2.00 → 1.00

## 五、每个模块 1 句话

- **Harness**：控制（ToolGovernor）/ 观测（trace+replay）/ 评测（golden+回归）三层。
- **记忆**：写（提取器 + Judge）→ 取（关键词∪余弦 + 时间衰减）→ 治（合并→淘汰→归档）。
- **Agent Loop**：外循环管一轮请求，内循环管一个 agent 的步进。
- **权限**：deny by default + 五道防线（沙箱/策略/参数/审批/租户）。
- **多智能体**：没有 agent 互聊；是"并行专家 + Supervisor 仲裁"。
- **RAG**：不是裸 RAG，是 Agentic RAG（agent 决定检索时机/多轮/纠错）。

## 六、答任何题的公式

```
① 给框架（一句话定义）
② 我项目怎么做的（落到组件名）
③ 一个数字 或 一个故事
④ 一个取舍（为什么这么做，代价是什么）
```

**例**（问"记忆怎么实现"）：
> "分三层（框架）→ 我长期记忆用 PG + 提取器 + Judge（项目）→ 150 例 99.3%（数字）→ 不用向量库，因为记忆要时效+频次（取舍）。"

## 七、记不住怎么办

- **别背细节**，背上面的框架；被追问时**从框架现场推导**。
- 数字只记 6 个；多了记不住也没必要。
- 不会的题：**诚实说"这块我没做" + 给"我会怎么做"**（比硬编强）。
- 主动埋钩子：说完框架**让面试官来问**，再展开——别一口气全倒。
